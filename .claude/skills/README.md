**Remotion** (31 de octubre 2026, pedido de Tomás): no vive en este repo, es un plugin instalado en su compu (`remotion@remotion`, versión 4.0.539). Hace animaciones de video con código: subtítulos, títulos y gráficos. Solo trae guías y ejemplos, sin avisos automáticos ni conexiones. Origen: [remotion-dev/claude-code-plugin](https://github.com/remotion-dev/claude-code-plugin). Gratis para personas y empresas chicas, según remotion.dev/license. Probado el 31 de octubre 2026: renderizó un MP4 vertical de 1080x1920 con Node 26. El proyecto tiene que estar fuera de `AppData` (ver `yo/compu-y-herramientas.md`).

Para actualizar una: volver a bajar el repo de origen, revisar qué cambió y reemplazar la carpeta.
