## El kit

- `auditor-visual` y `auditor-tecnico`: revisan en paralelo y no tocan nada.

Se carga solo con el Cerebro. El detector de impeccable se baja por sesión: `.claude/skills/impeccable/scripts/impeccable engine-probe`.
