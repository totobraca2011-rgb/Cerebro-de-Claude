# Monte Riko

Alfajores artesanales de Mar del Plata, hechos por Tomás Bracamonte.

| Archivo | Qué tiene |
|---|---|
| `brief.md` | Marca, historia, frases, productos y precios, cómo se compra, identidad visual y reglas |
| `instagram-voz.md` | Cómo habla Monte Riko en Instagram. Lo leen las skills de Instagram |
| `instagram.md` | El trabajo con la cuenta: proyecto de ordenar el perfil, cómo se reparte entre la nube y Chrome, y pendientes |
| `reels/` | Guiones y armado de cada reel |

| `mockups/` | Stickers y caja kraft, de referencia para la paleta |
| `manual-marca.pdf` | El manual de marca |

## Reglas fijas
- No inventar reseñas, cifras, clientes, premios ni ingredientes.
- No va el chocolate blanco. No va ninguna foto de Tomás. No hay foto del interior del marplatense: no se simula.
- El logo es siempre el SVG oficial.
