# Ganchos para reels

Lista que encontró Tomás en una publicación de Instagram (5 de noviembre 2026; no anotó de qué cuenta). Sirve para elegir el gancho de cada reel junto con los 26 de la skill `ig-reel` (`.claude/skills/ig-reel/hooks.json`). Se adaptan al voseo: "Si hacés", "Dejá de", "Hacé esto hoy".

| # | Gancho | Formato | Idea o tema |
|---|---|---|---|
| 1 | Si hacés esto... | Pregunta | Romper una creencia |
| 2 | Dejá de hacer... | Directo | Error común |
| 3 | 3 formas de... | Lista | Tips prácticos |
| 4 | Esto cambió todo... | Historia personal | Resultado o caso |
| 5 | El error número 1 que... | Educativo | Advertencia |
| 6 | Antes vs. después | Comparación | Transformación |
| 7 | Lo que nadie te dice... | Intriga | Información poco conocida |
| 8 | ¿Sabías que...? | Dato curioso | Estadística o dato |
| 9 | Así es como yo... | Tutorial | Paso a paso |
| 10 | Hacé esto hoy... | Acción directa | Motivación o urgencia |
| 11 | Esto me ahorró... | Resultado | Beneficio o herramienta |
| 12 | 3 errores que... | Lista negativa | Qué evitar |
| 13 | El método que uso... | Storytelling | Proceso personal |
| 14 | No necesitás... | Contraste | Romper una objeción |
| 15 | Mirá esto antes de... | Advertencia | Evitar un problema |
| 16 | La verdad sobre... | Opinión | Tema polémico |
| 17 | ¿Querés resultados? | Pregunta + pedido | Llamado a la acción |
| 18 | Esto funciona porque... | Explicación | Dar valor (la causa) |
| 19 | Copiá este método... | Tutorial | Paso a paso para copiar |
| 20 | Te muestro cómo... | Demostración | Mostrar en pantalla |
